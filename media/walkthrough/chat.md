# Chat with your code

Open the Gemma panel from the activity bar (the Gemma icon on the left).

- Type a question and press Enter.
- `/` for slash commands (`/explain`, `/fix`, `/tests`, `/docs`).
- `#` to attach a file (or `#terminal` for the last command's output).
- `@workspace` to search your indexed codebase semantically.
- Use the ☰ button to manage multiple chat sessions.

Your conversations are saved per workspace and survive restarts.
