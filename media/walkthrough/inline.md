# Edit code inline

Select some code and press **⌘⇧I / Ctrl+Shift+I** (or run *Gemma: Inline Edit*).
Type an instruction like "add docstrings" or "convert to async".

The rewrite streams directly into your editor, highlighted as it arrives:

- Accept with **⌘⏎ / Ctrl+Enter**
- Reject with **Esc**

The whole edit is a single undo step. You can also invoke it with no selection
to insert new code at the cursor — and a "✨ Fix with Gemma" quick-fix appears
on any error squiggle.
